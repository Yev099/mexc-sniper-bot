# MEXC Sniper Bot — Quick Start Guide

## Что это?

Бот для автоматического копирования фьючерсных сделок на бирже MEXC.  
Один аккаунт (мастер) торгует — остальные аккаунты (фолловеры) повторяют все его сделки автоматически.

## Что умеет?

- Копирует открытие/закрытие позиций в реальном времени (задержка ~500мс)
- Копирует лимитные ордера
- Копирует Take Profit и Stop Loss
- Настраиваемый множитель объёма для каждого фолловера
- Telegram бот для мониторинга и управления
- Синхронизация плеча (leverage)

## Установка за 5 минут

### 1. Клонируй репо

```bash
git clone https://github.com/Yev099/mexc-sniper-bot.git
cd mexc-sniper-bot
```

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Создай конфиг

```bash
cp .env.example .env
```

### 4. Заполни .env

Открой файл `.env` и заполни:

```env
# Мастер-аккаунт (с которого копируем)
MEXC_API_KEY=вставь_свой_api_key
MEXC_API_SECRET=вставь_свой_secret

# Фолловеры (кто копирует) — через запятую
# Формат: ИМЯ:КЛЮЧ:СЕКРЕТ:МНОЖИТЕЛЬ
# МНОЖИТЕЛЬ: 1.0 = такой же объём, 0.5 = половина, 2.0 = двойной
FOLLOWERS=vasya:key:secret:1.0,petya:key:secret:0.5

# Telegram бот (необязательно, но рекомендуется)
TELEGRAM_BOT_TOKEN=вставь_токен_от_botfather
TELEGRAM_CHAT_ID=вставь_свой_chat_id

# Настройки
POLL_INTERVAL=0.5
DEFAULT_LEVERAGE=20
COPY_LIMIT_ORDERS=true
COPY_TP_SL=true
```

### 5. Запусти

```bash
python main.py
```

Готово! Бот работает.

## Как получить API ключи MEXC

1. Зайди на [mexc.com](https://www.mexc.com) → Аккаунт → API Management
2. Создай новый ключ с правом **Futures Trading**
3. (Рекомендуется) Привяжи IP-адрес сервера
4. Скопируй Key и Secret в `.env`

## Как создать Telegram бота

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot`
2. Скопируй токен → `TELEGRAM_BOT_TOKEN`
3. Напиши своему боту любое сообщение
4. Открой: `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
5. Найди `"chat":{"id":123456789}` → это твой `TELEGRAM_CHAT_ID`

## Команды Telegram бота

| Команда | Что делает |
|---------|-----------|
| `/start` | Панель управления с кнопками |
| `/status` | Статус бота (работает/стоит) |
| `/positions` | Открытые позиции мастера |
| `/stop` | Поставить на паузу |
| `/resume` | Возобновить копирование |
| `/help` | Справка |

## FAQ

**Q: Безопасно ли давать API ключи боту?**  
A: Код open-source — проверь сам. Ключи хранятся только локально в `.env`, никуда не отправляются.

**Q: Можно ли иметь несколько фолловеров?**  
A: Да, добавь через запятую в `FOLLOWERS`.

**Q: Что если интернет отключился?**  
A: Бот продолжит с того момента, когда связь восстановится. Позиции которые открылись/закрылись пока был оффлайн — будут пропущены.

**Q: Можно ли менять объём для каждого фолловера?**  
A: Да, ratio в конфиге. 1.0 = такой же как мастер, 2.0 = двойной, 0.5 = половина.
